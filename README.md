# skakblix

**Afleysingavaktin** — vefsíða þjálfarateymis Skákdeildar Breiðabliks, veturinn 2026–2027.

- `index.html` — síðan í heild: æfingataflan sept–maí, afleysingapottur, frí-beiðnir og frí-skráning.
- Lifandi útgáfan með sameiginlegri vistun (þjálfarar taka tíma, senda beiðnir o.s.frv.) keyrir sem Claude-artifact; eintakið hér er skoðunarútgáfa/öryggisafrit — vistun er óvirk utan artifact-umhverfisins.
- Grunngögn: [Stóra planið (Google Sheets)](https://docs.google.com/spreadsheets/d/12Wa441GTjoUTqVFHTX4npCvQllNKJGk67Gg4__bxUx8/edit)
